# 🥬 小菜助手 (Shopping Assistant)

这是一个专为家庭日常买菜设计的极简网页版小工具，解决“今天吃什么”的纠结，以及“去菜市场怕忘买什么”的痛点。

## ✨ 核心功能
- **🎲 灵感盲盒**：随机推荐家常菜，解决选择困难症。
- **📝 今日清单**：记录需要购买的食材，买完可以打勾划掉。
- **🧹 一键清空**：支持删除单条记录，或一键清空已买物品。
- **💾 本地存储**：数据保存在浏览器本地，关闭网页再打开，清单也不会丢。

## 🛠️ 技术栈
- **HTML5**：搭建网页基础结构
- **CSS3**：自定义紫色主题、深青色卡片及圆角按钮样式
- **JavaScript**：实现随机推荐算法及清单增删改查逻辑

## 🚀 运行方式
直接在浏览器中双击打开 `index.html` 即可使用。
